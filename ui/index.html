USB / CI-V

Connect your radio

  1. Use an Icom OPC-2350LU compatible DATA cable and its USB driver. OPC2351 has not been verified.
  2. On the radio: MENU → Function → CI-V → CI-V (DATA Jack) → ON (Echo Back OFF).
  3. Set CI-V address to 86h and baud rate to match below.
  4. Click Choose COM port, select the cable’s COM number, then click Connect USB. No browser or internet connection is needed.
